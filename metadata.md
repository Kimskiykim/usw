# metadata

- **Название:** usw
- **Автор:** Леонид Ким
- **Версия:** 0.2.0
- **Описание:** Создание, поиск, оценка и выполнение рабочих процессов (flow) в Markdown через Qwen Code, Codex, Claude Code и GigaCode; сохранение состояния работы между сессиями (handoff).
- **Применимость:** Повторяемые задачи разработки, проверки и планирования, для которых нужен явно описанный порядок действий; продолжение работы в новой сессии с сохранённым контекстом.
- **Использование:** Установить USW для выбранного агента по инструкции в [README.md](README.md#установка). Открыть новую сессию, вызвать `/usw-init`, создать flow через `$usw-create-flow <описание>` и выполнить его через `$usw-run-flow <name> "<input>"`.
- **Эксперимент:** Работоспособность кода проверяется командой `python3 -m unittest discover -s tests -v`. Следование модели инструкциям проверяется локальными поведенческими сценариями: `USW_EVAL_RUNNER='<команда runner>' python3 evals/run_evals.py --runs 5`; оценивается доля успешных запусков создания, поиска, оценки и выполнения flow, включая соблюдение границ разрешений. Методика и ограничения описаны в [evals/README.md](evals/README.md). Сравнительные замеры времени и затрат с USW и без него в репозитории не зафиксированы.
