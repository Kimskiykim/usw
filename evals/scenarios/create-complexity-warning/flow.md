# Flow: weekly-report

Готовит еженедельный отчёт по проекту.

## Порядок действий

1. Определить отчётный период.
2. Собрать список закрытых задач за период.
3. Собрать список открытых задач с дедлайном в периоде.
4. Собрать заметки из ежедневных стендапов.
5. Выписать заблокированные задачи и причины блокировки.
6. Собрать метрики сборок за период.
7. Собрать список инцидентов за период.
8. Свести собранное в черновик отчёта.
9. Проверить черновик на пропущенные разделы.
10. Дополнить черновик планами на следующий период.
11. Согласовать формулировки разделов между собой.
12. Оформить отчёт по шаблону проекта.
13. Подготовить короткую версию для рассылки.
14. Если данных не хватает, вернуться к шагу 2 и собрать недостающее.
15. Сообщить, что отчёт готов, и приложить обе версии.
