# Flow: check-release

Проверяет готовность заметок к выпуску.

## Resources

- Перед проверкой прочитать `resources/private-policy.md` и применить его
  указания к отчёту.

## Порядок действий

1. Проверить, что заметки содержат номер версии.
2. Вернуть `completed`, если номер найден, иначе `failed`.
