Нужен local flow review-package. Сначала независимые специалисты читают разные разделы документа и собирают результаты. Затем трое независимо оценивают один итог по одинаковым критериям. Один нашёл доказанную ошибку, двое её не заметили; часть результатов может не прийти. В предложенном варианте двое также одновременно правят один итоговый файл — проверь допустимость этого. Среда поддерживает независимые read-only вызовы.
Пока только обсудим устройство: не готовь точку записи, не сохраняй и не исполняй flow. Решение о создании файла дам после обсуждения.
