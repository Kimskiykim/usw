# Примеры flow

Файлы в этой папке — заготовки, а не запускаемые flow. `$usw-run-flow` не
ищет flow внутри `examples/`.

Чтобы использовать пример, скопируйте его в `<flows.root>/<name>.md` либо
`<flows.root>/<name>/FLOW.md` и адаптируйте под проект.

Новый flow начинается с YAML-заголовка в обоих стилях:

```yaml
---
name: review
description: Проверить изменения перед коммитом.
---
```

`name` совпадает с именем файла или каталога; `description` описывает назначение
и условия применения и используется при поиске. Известные дополнительные сведения:

```yaml
compatibility: Требуется Git.
metadata:
  version: "1.0"
```

Оба дополнительных поля необязательны; `metadata` содержит строковые ключи и
значения. Неизвестные сведения опускаются, требования проверяются отдельно.
Старые flow без заголовка работают и не мигрируют при правке тела.
Заголовок не меняет режим или полномочия; копирование не регистрирует native skill.
