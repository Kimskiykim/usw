# Инструкции Codex для проекта

Писать пользовательские тексты, сообщения и документацию на русском языке.
Использовать английский только для кода, команд, путей, идентификаторов,
общепринятых технических терминов и обозначений, которые нельзя точно или
естественно передать по-русски.

Работать серией небольших, независимо оцениваемых изменений:

- одно изменение — один наблюдаемый результат;
- у каждого изменения есть ясный критерий готовности и отдельная проверка;
- после каждого изменения кратко показывать, что изменилось, как проверить и
  какой результат получен;
- не смешивать функциональность, рефакторинг и несвязанные исправления;
- большой scope сначала разбивать на упорядоченные мини-изменения;
- не делать и не предлагать единым пакетом изменение примерно на 1000 или
  более добавленных/изменённых строк без явного согласия пользователя.
