# component-installation Specification

## Purpose

Определяет сохранность прежних компонентов при обработанной ошибке
POSIX-установщика USW и границы частичного обновления пакета.

## Requirements

### Requirement: Preflight предшествует изменению установки
`install.sh` MUST проверять полный набор исходных skills и commands и
конфликты назначений всех выбранных агентов до изменения любых установленных
компонентов, включая legacy. Отсутствующий исходный каталог skill, его
`SKILL.md` или исходная command MUST давать ненулевой exit без изменения
установки. Существующий target без `--force` MUST отклоняться до mutation.

#### Scenario: Отсутствует поздний исходник
- **WHEN** исходная command отсутствует, а ранние skills и legacy уже установлены
- **THEN** установка завершается ошибкой до изменения любого из них

#### Scenario: Конфликт у последнего выбранного агента
- **WHEN** режим `all` без `--force` обнаруживает занятый target у Claude Code
- **THEN** назначения Qwen Code, Codex и Claude Code остаются неизменными

### Requirement: Ошибка подготовки сохраняет прежний компонент
Установщик MUST полностью подготовить новый skill или command, включая
удаление bytecode-кэша из копии skill, до удаления или перемещения прежнего
компонента. Ошибка копирования либо подготовки MUST сохранять прежние bytes
и тип записи по исходному target, возвращать ненулевой exit и не оставлять
неполный новый компонент по этому target.

#### Scenario: Копирование skill записало часть файлов и упало
- **WHEN** подготовка замены существующего skill завершается ошибкой после частичной записи
- **THEN** прежнее дерево skill по target неизменно и неполная копия не активирована

#### Scenario: Копирование command упало
- **WHEN** копирование новой command записало часть её bytes и завершилось ошибкой
- **THEN** прежняя command не удалена и не усечена

#### Scenario: Очистка bytecode в подготовленной копии упала
- **WHEN** копирование skill завершено, но удаление bytecode из копии завершилось ошибкой
- **THEN** прежний target неизменен, exit ненулевой и подготовленная копия не активирована

#### Scenario: Первая установка компонента не удалась
- **WHEN** target отсутствовал до неудачной подготовки
- **THEN** по target не появляется неполный компонент

### Requirement: Неудачное переключение не уничтожает прежние bytes
При обработанной ошибке переключения подготовленного компонента установщик
MUST восстановить прежний target. Если восстановление также не удалось,
он MUST сохранить прежний компонент отдельно, сообщить точный путь и вернуть
ненулевой exit. Сообщение об успешной установке компонента MUST появляться
только после успешного переключения.

#### Scenario: Активация подготовленного skill не удалась
- **WHEN** прежний skill уже отведён в backup, но переключение нового завершилось ошибкой
- **THEN** прежний skill восстановлен по target, ошибка видима и успех не заявлен

#### Scenario: Восстановление также завершилось ошибкой
- **WHEN** вернуть backup по target не удалось
- **THEN** полный backup с прежними bytes сохранён, сообщённый путь ведёт к нему,
  cleanup не удаляет эту последнюю сохранную копию

### Requirement: Результат ошибки и временные объекты явны
При обработанном отказе установщик MUST сообщать имя или путь неудавшегося
компонента и ненулевой exit. После успеха и обработанного отказа он MUST
удалять собственные staging/backup-объекты, кроме последней сохранной копии
при неудачном восстановлении. При невозможности cleanup он MUST сообщить
оставшийся путь, не удаляя сохранную прежнюю версию ради очистки.

#### Scenario: Подготовка не удалась
- **WHEN** частичная новая копия не активирована и cleanup доступен
- **THEN** временная копия удалена, компонент назван в ошибке и прежний target сохранён

#### Scenario: Обновление успешно
- **WHEN** новая версия полностью установлена
- **THEN** staging и прежний backup удалены, лишние файлы старого skill отсутствуют

#### Scenario: Финальный cleanup завершился ошибкой
- **WHEN** новый полный компонент активирован, но финальная очистка оставила временный объект
- **THEN** exit ненулевой, активный target остаётся новым полным компонентом,
  ошибка называет точный оставшийся путь; итоговый успех не заявлен

### Requirement: Leaf symlink не перенаправляет установку
Существующая или dangling symlink по конечному target MUST считаться занятым
назначением. Без `--force` установщик MUST отказать; с `--force` он MUST
заменить саму запись ссылки подготовленным компонентом, сохраняя объект,
на который она указывает. Требование ограничено конечной записью target;
обработка родительских symlink вне scope. Workspace write-safety USW не меняется.

#### Scenario: Dangling symlink без force
- **WHEN** конечный target является dangling symlink и `--force` не указан
- **THEN** установка отказывает до mutation и сохраняет ссылку

#### Scenario: Force заменяет ссылку на внешний объект
- **WHEN** конечный target skill или command является ссылкой и указан `--force`
- **THEN** target становится обычным новым компонентом, внешний объект неизменен

### Requirement: Ошибка раскрывает предел частичного обновления
Ненулевой результат после успешной замены других компонентов MUST сообщать
о возможной смешанной редакции установки и необходимости проверить её перед
новым использованием. Установщик MUST NOT обещать откат всех компонентов
или успешное завершение всего пакета при ошибке одного компонента.

#### Scenario: Позднее копирование упало после ранней замены
- **WHEN** ранний компонент обновлён успешно, а подготовка следующего завершилась ошибкой
- **THEN** раннее обновление сохраняется, прежний следующий компонент сохранён,
  общий exit ненулевой и возможная смешанная редакция явно обозначена
