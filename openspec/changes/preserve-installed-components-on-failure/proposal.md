# Proposal

## Why

В `install.sh:84-87` прежний skill удаляется до `cp -R`; ошибка копирования
оставляет компонент утраченным или неполным. AUD-S10 по-прежнему подтверждён
этой последовательностью; безопасное обновление нужно для свежих проверок
USW в текущей цели, а существующие четыре теста проверяют только успех
и обычный отказ перезаписи.

## What Changes

- Проверять наличие всех поставляемых исходников и конфликты выбранных
  назначений до первой mutation, включая удаление legacy-компонентов.
- Готовить полную копию каждого skill/command до замены прежнего компонента;
  при ошибке подготовки сохранять прежние bytes, при ошибке переключения
  восстанавливать прежнее назначение, сохраняя backup при неудаче восстановления.
- Учитывать существующие и dangling symlink назначения как занятые записи:
  обычная установка отказывает, `--force` заменяет саму ссылку без записи
  в её target. Раскрывать частичный результат нескольких компонентов.

## Scope

Один результат: обработанная ошибка установки одного компонента не уничтожает
его прежнюю версию. POSIX `install.sh`, выбранные `all|qwen|codex|claude`,
раздельные source/target roots и завершающиеся системные команды.
Тесты с изолированными каталогами и управляемыми ошибками, краткая документация,
актуализация только AUD-S10 и его строки индекса после приёмки.

## Non-goals

Глобальная транзакция всех компонентов/агентов, crash/power-loss recovery,
изменение обработки родительских symlink, конкурентная подмена родителей,
изменение native plugin managers, Windows
shell installer, исправление AUD-S11 (совпадение source/target), AUD-S12
и остальных карточек. Исходники skills, flow, их runtime и модель полномочий
не меняются. Весь исторический backlog этим change не закрывается.

## Capabilities

### New Capabilities

- `component-installation`: безопасная подготовка и замена компонентов
  POSIX-установщиком с проверяемым результатом ошибки.

### Modified Capabilities

Нет. `project-initialization` описывает `/usw-init` внутри проекта;
`flow-discovery` сохраняет свой контракт удаления legacy-router при успешном
`--force`, `flow-behavior-evaluation` — исключение evals из установки.

## Impact

`install.sh`, `tests/test_install.py`, обзор обновления в `README.md`;
новая основная spec появится при sync. После независимой приёмки — история
`usw/backlog/AUD-S10.md` и соответствующая строка `usw/BACKLOG.md`.
Новых зависимостей и runtime нет. Реальная установка — отдельный шаг
с исключительным правом записи и последующим новым рабочим чатом.
