# Проверка

Дата: 2026-10-08.

## Изменённое поведение

Ручной handoff требует прямого вызова человеком команды, skill или явной
просьбы использовать handoff. Общие просьбы сохранить состояние и продолжить
работу не активируют skill; граница стоит до чтения конфигурации и состояния.
Служебные вызовы из flow сохраняют прежний контракт и конфигурацию USW.

Native metadata запрещает implicit invocation. Два отрицательных сценария
получают нейтральную вводную harness через `explicit_invocation: false`;
прежние сценарии по умолчанию сохраняют имитацию явного вызова.

## Выполненные проверки

- Новый тест native policy сначала не проходил, после правки metadata проходит.
- Два теста нейтральной вводной сначала не проходили; после правки все
  58 тестов harness проходят. Проверены default `true` и отказ для неверных типов.
- Адресные проверки: 52 handoff, 58 harness, 19 platform, 4 end-to-end и
  1 package handoff — всего 134 теста, все проходят.
- Полный `python3 -m unittest discover -s tests -q`: 281 тест, 280 проходят;
  один прежний `FileNotFoundError` в `test_codex_marketplace_points_to_plugin`
  из-за отсутствия `.agents/plugins/marketplace.json`. Этот сбой уже воспроизведён
  на чистом HEAD при проверке предыдущего change; данной правкой файл не затронут.
- `openspec validate require-explicit-manual-handoff --strict`: проходит.
- `openspec validate --all`: 22 из 22 проходят, с прежними предупреждениями
  о длинных requirements. Глобальная strict-проверка ранее выявила такие же
  предупреждения на HEAD; новый change проходит strict отдельно.
- `git diff --check`: проходит.

## Первоначальные ограничения

При первоначальной проверке `handoff-generic-save`, `handoff-generic-resume`,
`handoff-explicit-disabled` были пропущены: runner не был настроен.
Файловые markers сценариев не доказывают отсутствие чтения и полную
неизменность байтов; для этого требуется наблюдение tool transcript.
Передача candidate skill в prompt не проверяет native discovery хоста.

Тогда были изменены только исходники пакета; глобальные копии не обновлялись.
Runtime хранения handoff и runner flow в этом change не менялись; прежние
правки удаления миграций относятся к отдельному change.

## Дополнительная проверка установленного пакета, 2026-10-09

Глобальные копии Codex, Claude и Qwen обновлены и сверены с исходниками.
Три целевых handoff harness scenarios прошли по 1/1. Для explicit-disabled
первый ответ был семантически верным, но не прошёл точную проверку формата;
формат запрошен в input, повторная проверка прошла. Первый результат сохранён.

В отдельных нативных сеансах Codex CLI обычные сохранение и продолжение
не активировали handoff. Прямой show соблюдал включённую/отключённую настройку.
Flow с handoff выполнил Begin/Outcome и сохранил completed operation;
при handoff: false flow выполнился без чтения и изменения handoff.
Выводы подкреплены tool transcripts и сравнением файлов, а не только markers.
Нативное поведение desktop GUI, Claude и Qwen отдельно не проверялось.
