## Why

`usw-create-flow` сейчас завершает работу сразу после создания и проверки flow.
Пользователь не получает отдельной возможности запросить анализ получившейся
структуры, а автоматическое добавление «улучшений» смешало бы исходный запрос с
неподтверждёнными предположениями агента.

## What Changes

- После успешного создания или обновления flow предлагать пользователю
  отдельный опциональный анализ формулировкой без заранее заявленных идей.
- Выполнять анализ только после явного согласия пользователя.
- Рассматривать в анализе только применимые улучшения: verification, review,
  HITL, развилки, feedback loops, пределы повторов и escalation.
- Сначала показывать рекомендации, не меняя flow автоматически.
- Применять только выбранные или явно одобренные пользователем рекомендации.
- Сохранять существующие default/structured режимы, path safety и запрет на
  исполнение созданного flow.

## Capabilities

### New Capabilities

- `flow-authoring-assistance`: Двухфазный контракт создания flow и
  опционального анализа возможных улучшений с отдельным человеческим согласием
  на анализ и применение.

### Modified Capabilities

Нет.
