исправив дефекты; не обещать работу остальных USW skills без Python.

## Объём

Производные инструкции init приведены к действующим project-initialization
и workspace-configuration. Новых требований нет, `skip_specs: true`.
Python runtime не менялся. Две правки F08 выполнены последовательно:
обработка partial write, затем сохранение существовавшего HANDOFF.

Это наблюдение по состоянию после заданного сбоя, не реальная I/O fault

## Ограничения

Все 45 harness behavior scenarios загружаются, но пропущены без настроенного
runner. Добавлены init-fallback-partial-write и init-fallback-existing-handoff.
Их markers не доказывают byte-for-byte сохранность; она отдельно проверена
в адресном наблюдении модели. Это не полный fault-injection прогон и не
доказательство безопасности при конкурентной подмене пути.

Исправлены исходники; установленные глобальные skills не обновлены.
