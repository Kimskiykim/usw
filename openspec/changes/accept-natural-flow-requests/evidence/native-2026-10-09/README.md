# Проверка установленного пакета и активации

Дата: 2026-10-09. AUD-I07 закрыта по наблюдениям ниже.

## Установка

`sh ./install.sh all --force` обновил существующие глобальные установки Codex,
Claude и Qwen: по 6 skills и 10 команд. Для каждой установки проверено побайтное
совпадение с исходниками: 52 файла skills без cache и 10 файлов команд.
Существующие дополнительные skills Qwen не удалялись. Перед обновлением
сохранена резервная копия по пути `backup` из [manifest.json](manifest.json).
Четыре теста установки прошли. Для обычного использования обновлённых metadata
нужен новый сеанс: каталог уже открытого чата может содержать прежние descriptions.

## Нативные сеансы Codex

Каждый случай выполнен в отдельном временном проекте новым процессом Codex CLI
0.146.0. Модель не переопределялась. Флаги и шаблон запуска — в manifest.json.
Skill instructions в prompt не передавались: использовались установленные skills.
Флаги отключали пользовательские настройки и rules для изоляции наблюдения.

| Случай | Наблюдение |
| --- | --- |
| find | Обычная просьба загрузила установленный finder и вызвала resolve; найден flow, запуск отсутствует. |
| assess | Обычная просьба загрузила assessor и вызвала inspect; получена оценка без запуска. |
| mention | Простое упоминание flow: вызовов tools нет. |
| unclear | Запрошено имя flow до доступа к конфигурации и каталогу. |
| generic-save | Создан только запрошенный notes/session.md; handoff не вызывался. |
| generic-resume | Продолжено объяснение; вызовов tools нет. |
| explicit-disabled | Прямой вызов при handoff: false сообщил причину; состояние handoff не читалось и не менялось. |
| explicit-enabled | Прямой вызов выполнил show; пустое состояние осталось прежним. |
| flow-enabled | Runner выполнил Begin, действие flow и Outcome; operation сохранена со статусом completed. |
| flow-disabled | Runner выполнил действие flow; служебных вызовов handoff и чтения его состояния нет. |

Все 10 процессов завершились с кодом 0. Отдельно проверены 30 условий,
перечисленных в [native-checks.json](native-checks.json): команды и ответы по
JSONL, побайтная неизменность исходных файлов и разрешённые новые файлы.
`fixtures/before/<case>/` содержит исходный проект; `fixtures/after/<case>/` —
только созданные или изменённые файлы. Отсутствие чтения установлено по tool
transcript, а не по одному файловому sentinel.

Для повторения скопировать fixture случая в отдельный каталог и подать
соответствующий `<case>.input.txt` через stdin по шаблону manifest.json.
`<case>.jsonl` сохраняет команды, их результаты и итоговые ответы; скрытых
рассуждений в этих логах нет. Подход с JSONL событиями соответствует
[официальному примеру eval skills](https://developers.openai.com/blog/eval-skills).

## Harness

Runner указан в сохранённых отчётах. В этом слое harness передаёт инструкции
кандидатов; это отдельная проверка поведения, а не нативного выбора skill.

- Первый проход: generic-save и generic-resume — 1/1; explicit-disabled — 0/1.
  Ответ правильно сообщил отключённый handoff, но раздельно назвал поле и false,
  поэтому проверка точной строки его отвергла. Исходный отчёт и transcript
  сохранены в harness-report.txt и harness-round1/.
- В input explicit-disabled добавлено требование назвать поле и значение одной
  YAML-строкой; ожидаемый marker в prompt не раскрывается. Product instructions
  не менялись. Повторный проход explicit-disabled и шесть find/assess cases —
  7/7; отчёт и transcripts сохранены в harness-round2-report.txt и harness-round2/.
- Итого актуальные девять целевых сценариев наблюдались успешно по одному разу.
  Остальные behavior scenarios в этой проверке не выполнялись.

После уточнения input все 58 unit-тестов harness прошли. Оба changes
accept-natural-flow-requests и require-explicit-manual-handoff прошли strict
validation; `git diff --check` не обнаружил ошибок. Число P3 в бэклоге сверено
с оставшимися 23 карточками после удаления AUD-I07.
Независимое ревью подтвердило установленные файлы, traces и изменения всех
10 fixtures; actionable defects не обнаружены.

Это наблюдения одной версии Codex CLI и конкретных сеансов, а не гарантия
каждого будущего ответа. Нативная активация в desktop GUI, Claude и Qwen отдельно
не проверялась; для последних двух подтверждено обновление файлов установки.
