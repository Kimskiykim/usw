# Удаление совместимости HANDOFF

## Context

См. `proposal.md`. Role-based формат уже отклоняется. Остались преобразование
single-state в router и поддержка operation documents без recovery metadata.
Современный Begin уже создаёт полный документ; добавлять новую форму не нужно.

## Goals / Non-Goals

Сохранить routed execution, safe-access и сериализацию переходов. Удалить ветки
преобразования и fallback recovery fields. Не менять статусы, identity,
конфигурацию, правила активации и пользовательские файлы.

## Decisions

- Router читается непосредственно через существующий parser; удалить
  `render_idle`, `handoff_format` и преобразование single-state.
- Operation parser требует полный набор metadata и sections. Удалить
  автоматическое дополнение Summary/Started/Workspace в Outcome и Save.
- Begin сохраняет exclusive-create и rollback собственного нового документа;
  удалить режим установки существующего migration document.
- Старые fixtures перенести на router; старое содержимое оставить только как
  отрицательные тестовые данные. Покрыть отказ всех читающих и изменяющих команд,
  сохранив проверки нового Begin/Outcome/Save/Finish/Cleanup.
- Альтернатива «оставить parser и только отключить миграцию» отвергнута:
  она оставляет старую форму operation доступной и не выполняет запрос полностью.

## Risks / Trade-offs

Старые сохранённые состояния перестанут открываться → вернуть явную ошибку,
оставить файлы нетронутыми и раскрыть изменение в README. Не отклонять уже
актуальные документы с явными `unknown`: это сохранённые факты, не миграция.

## Migration Plan

Обновить исходники, specs и installed product skills обычным способом после
проверки. Пользовательское состояние не преобразовывать и не удалять. При
необходимости отката вернуть прежнюю версию кода; формат новых данных не меняется.
