# Proposal

## Why

AUD-F05: run skill обещает `in_progress` после ошибки Outcome, хотя authoritative
документ может сохранить прежний `paused` или уже получить `completed` до ошибки
обновления router. Пользователю нужен достоверный отчёт о сохранённом состоянии
и результате работы, без повторного исполнения изменений.

## What Changes

- Заменить обещание статуса после ошибки проверкой точной root operation через
  существующий `show <project> <operation-id>`; при недоступном чтении явно
  сообщать, что текущий сохранённый статус не подтверждён.
- Разделять ошибку записи, прочитанный статус и сохранённые сведения: исход flow,
  существенные результаты и ограничения сообщать человеку также при ошибке.
- Уточнить служебное основание этого чтения в run/manage инструкциях, сохранив
  запрет автоматического повтора root/child изменений.
- Добавить адресные backend-регрессии и проверить текстовый путь обычными
  ролевыми чатами; сохранить проверки отключённого и ручного handoff.
- По уточнению пользователя проверять переносимый контракт без зависимости
  готовности от конкретной LLM, host, effort или специального model runner.

## Scope

Один результат: после ошибки Outcome исполнитель честно сообщает состояние
точной операции и сохранность результатов. Изменяются `live-operation-state`,
узкие разделы двух `SKILL.md`, необходимые tests и переносимые fault fixtures.
Правило проверки в `docs/goals/usw-improvement-next.md` уточняется без смены
ролей команды. Связанные
commands/references проверяются на дубли неверного обещания; правятся только
при обнаруженном противоречии этому результату.

## Non-goals

Переписывание backend, транзакция document/router, rollback Outcome, новые
статусы, обход валидации router, автоматические repair/retry/Resume/Begin,
изменение manual activation или `allow_implicit_invocation`, S10, установка
и закрытие других кандидатов. При `handoff: false` доступ к state запрещён.
Специальные CLI/API inference, availability probes, model/effort benchmark
и новая инфраструктура eval не требуются; общий существующий harness сохраняется.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `live-operation-state`: статус после ошибки определяется проверенным
  authoritative документом; служебное exact чтение разрешено внутри flow,
  ошибка чтения означает явную неопределённость.

## Impact

Public CLI, identity, форматы router/document и порядок записи сохраняются.
Backend уже записывает документ до snapshot; exact Show читает документ без
обновления snapshot, но требует валидный доступный router. Изменение затрагивает
`skills/usw-run-flow/SKILL.md`, `skills/usw-manage-handoff/SKILL.md`,
`tests/test_handoff_state.py`, соответствующие stable-token проверки и
существующие F05 fixtures/scenarios в полезной для локальной проверки части.
Новых зависимостей нет. S10 закрыт и закоммичен; apply F05 приостановлен до
принятия обновлённого planning `f05-c2`. Этот update меняет только план и цель,
не завершает реализацию и не объявляет прежние CLI попытки успешными.
