## Context

См. proposal.md. Cleanup уже валидирует операции, отменяет их регистрацию под общей блокировкой и удаляет точные пути документов и кандидатов.

## Goals / Non-Goals

**Goals:** Добавить явный выбор всех статусов, сохранив тот же безопасный transition.

**Non-Goals:** Рекурсивное удаление каталога handoffs и автоматическая очистка orphan-файлов.

## Decisions

- Флаг CLI `--all` передаётся в `cleanup_handoffs` как `all_operations=True`. Без него сохраняется фильтр terminal statuses.
- Обёртка `/usw-handoff` различает обычный Cleanup и `cleanup --all`, передавая флаг как режим очистки.
- Все выбранные документы валидируются до записи router. Удаление использует существующий путь Cleanup, без новой функции очистки.
- Пустой router даёт пустой список; отключённый handoff остаётся нетронутым.

## Risks / Trade-offs

- Флаг удаляет recovery-контекст активных операций → исполнитель использует его только по явному запросу пользователя.
