# Engineering Standards

## Язык и стиль

- Русский — основной; английский только для кода, команд, путей,
  идентификаторов и непереводимых терминов (см. `GIGACODE.md`).
- Имена flow и slugs — kebab-case.
- Все текстовые файлы — LF-only.

## Дисциплина изменений

- Одно изменение — один наблюдаемый результат и отдельная проверка;
  критерий готовности определяется до правки (`GIGACODE.md`).
- PR Size Rule: объём `tasks.md` change укладывается в один PR; иначе
  делить по естественным границам.
- Зелёные коммиты через stash-verify: перед коммитом застэшить
  незакоммиченное, прогнать тесты на индексе, вернуть stash.

Рабочие файлы, журналы и перенос между слоями — в
`08-process-conventions.md`.

## Проверки

```bash
python3 -m unittest discover -s tests -v
```

Behavior evals — локально, после правки любого `SKILL.md`:

```bash
python3 evals/run_evals.py
```

Код готов, когда детерминированные тесты зелёные. Python 3.10+.
