# Обработка списка элементов

Предлагать, когда одинаковая процедура применяется к множеству однотипных
элементов. Сначала зафиксировать список, потом обрабатывать:

```markdown
1. Построить конечный список элементов и показать его.
2. LOOP по списку, не более `<длина списка>` итераций:
   - обработать элемент по единой процедуре;
   - ошибку элемента записать в отчёт и перейти к следующему.
3. Показать сводный отчёт: обработано, пропущено, ошибки.
```

Правила: список фиксируется до обработки и не пополняется на ходу; ошибка
элемента не прерывает batch — прерывает только blocking-препятствие,
общее для всех элементов. Список длиннее ~10 элементов — сигнал сложности:
предложить разбить на отдельные запуски.
