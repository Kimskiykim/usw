# Сбор недостающих входов

Предлагать, когда flow использует внешние входы или предусловия и содержит
side effects. Все проверки — до первого side effect, чтобы не спотыкаться о
недостающее посреди сделанной наполовину работы:

```markdown
1. Проверить все входы и предусловия списком.
2. GATE полноты:
   - всё есть → продолжить;
   - чего-то нет → вернуть `decision_required` с полным списком
     недостающего одним сообщением.
```

Не спрашивать недостающее по одному. Один `decision_required` с полным
списком лучше трёх последовательных вопросов.
