# Независимые оценки

Предлагать для нескольких независимых оценок одного предмета: [Voting](../patterns/voting.md), форма [Fan-out / Fan-in](../patterns/fan-out-fan-in.md).
Задать один предмет и версию, общие критерии, независимые входы без ответов других оценщиков и правило сведения. Например: принять лишь при проверке всех критериев и отсутствии неразрешённых подтверждённых замечаний.

```markdown
PARALLEL:
- CALL SUBAGENT `reviewer-a`: требования и фактический результат; вернуть вывод, evidence и непроверенное;
- CALL SUBAGENT `reviewer-b`: те же входы, без первого ответа; вернуть свою оценку.
1. Свести оценки по объявленному правилу; отдельно показать пропуски и разногласия.
2. GATE: нет обязательной оценки или осталось подтверждённое замечание → `decision_required`; критерии подтверждены → `completed`.
```

В обычном стиле: получить независимые оценки, сопоставить доказательства и решить по объявленному правилу. Большинство не отменяет подтверждённое замечание. Для одной оценки достаточно [Ревью субагентами](subagent-review.md); обсуждение ответов меняет независимость.
