# Адаптивная интенсивность

Предлагать, когда один flow обслуживает задачи разного риска и фиксированная
интенсивность контроля либо душит простые случаи, либо недоконтролирует
опасные. Число проверок, ревьюеров и точек участия человека выбирается по
объявленным сигналам риска:

```markdown
1. GATE уровня риска по объявленным сигналам:
   - затронуты security-пути, данные или миграции → high;
   - изменение без тестов либо мульти-компонентный scope → medium;
   - иначе → low.
2. Сообщить выбранный уровень и сработавшие сигналы до исполнения.
3. Выполнить по уровню:
   - low → выполнить и показать итог;
   - medium → выполнить, затем одно ревью субагентом;
   - high → CALL HUMAN `owner` до действия, затем два независимых ревью.
```

Правила: сигналы — только наблюдаемые факты (пути, наличие тестов, размер
изменения, необратимость), не самооценка сложности; 2–3 уровня, состав
каждого объявлен в тексте flow; адаптивность только добавляет контроль над
минимумом — обязательное подтверждение необратимого внешнего действия не
отключается ни на каком уровне; при неопределённости сигналов выбирать более
высокий уровень.
