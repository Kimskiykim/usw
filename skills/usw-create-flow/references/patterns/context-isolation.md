# Изоляция контекста субагентов

- **Проблема:** Лишняя история и промежуточные рассуждения перегружают основной контекст.
- **Применять:** Host позволяет отделить контекст работы и явно задать релевантные входы.
- **Не применять:** Агенту недоступны исходные требования или host не позволяет обещанный режим контекста.
- **Устройство:** Передать нужные источники и контракт краткого ответа; механизм сочетается с оркестрацией и Claim Check.
- **Ограничения:** Работает и последовательно, и с одинаковыми моделями. Полная история по просьбе пользователя допустима, но это не чистый начальный контекст.
- **Пример USW:** Reviewer получает всю историю по запросу пользователя и прямые требования; возвращает краткие находки, не копируя исследовательский диалог.
- **Проверка пользы:** Измерить объём входа и возвращаемых данных, качество находок; не обещать экономию от одного слова «субагент».
- **Происхождение:** [LangChain subagents](https://docs.langchain.com/oss/python/langchain/multi-agent/subagents) описывает изоляцию; правила реального host и адаптация USW определяют доступный режим.

Рецепты: [Оркестрация с субагентами](../recipes/subagent-orchestration.md), [Передача артефактов](../recipes/artifact-passing.md).
