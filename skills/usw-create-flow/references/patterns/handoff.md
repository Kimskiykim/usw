# Передача управления — Handoff

- **Проблема:** Дальнейший диалог должен вести другой специалист.
- **Применять:** Host действительно передаёт активное управление и поддерживает понятные границы ответственности.
- **Не применять:** Есть только вызов субагента с возвратом либо сохранение recovery state.
- **Устройство:** Передать управление с контекстом и условием возврата; это условный подход без готового рецепта USW.
- **Ограничения:** Не команда recovery-handoff USW и не перенос root ownership. Без механизма host — координируемое делегирование с возвратом.
- **Пример USW:** Специалист принимает следующий запрос пользователя только после подтверждённой передачи управления средой.
- **Проверка пользы:** Проверить, кто фактически отвечает на следующий ввод и не потеряны ли требования.
- **Происхождение:** [Microsoft](https://learn.microsoft.com/en-us/azure/architecture/ai-ml/guide/ai-agent-design-patterns): Handoff orchestration. Здесь объяснение подхода, не обещание поддержки в USW.
