# Передача по ссылке — Claim Check

- **Проблема:** Объёмный результат перегружает сообщения и повторно копируется.
- **Применять:** Следующему участнику доступен объявленный артефакт и его актуальная версия.
- **Не применять:** Короткого ответа достаточно или получатель не может прочитать указанный источник.
- **Устройство:** Передать ссылку и краткий смысл вместо содержимого; применить рецепт передачи артефактов.
- **Ограничения:** Ссылка не доказывает корректность. Нужны прямые требования и фактический результат для проверки; это не Blackboard.
- **Пример USW:** Исследователь сохраняет отчёт, координатор передаёт путь; reviewer сверяет сам отчёт и исходные требования.
- **Проверка пользы:** Сравнить объём пересылаемого контекста и потери информации; проверить, что ссылки действительно читаются.
- **Происхождение:** Название из [Enterprise Integration Patterns](https://www.enterpriseintegrationpatterns.com/patterns/messaging/StoreInLibrary.html). Передача файлов между агентами — адаптация, а не реализация messaging middleware.
