# Независимые оценки — Voting

- **Проблема:** Одно суждение может пропустить ошибку или зависеть от случайного выбора.
- **Применять:** Нужны независимые оценки одного предмета по общим критериям.
- **Не применять:** Нужны разные части работы или обсуждение с ответами на аргументы друг друга.
- **Устройство:** Дать проверяющим один предмет, затем применить заранее выбранное правило сведения с evidence.
- **Ограничения:** Большинство не доказывает корректность и не отменяет подтверждённое замечание; недостающие оценки указывать.
- **Пример USW:** Два reviewer отдельно проверяют один план; координатор разбирает каждое подтверждённое возражение.
- **Проверка пользы:** Измерить дополнительные найденные ошибки и цену повторных оценок.
- **Происхождение:** [Anthropic](https://www.anthropic.com/engineering/building-effective-agents): Parallelization / Voting; доказательное сведение — адаптация USW, без машинной гарантии консенсуса.
