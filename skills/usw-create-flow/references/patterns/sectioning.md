# Независимые части — Sectioning

- **Проблема:** Одна задача содержит разные независимые части.
- **Применять:** Части можно выполнить без результатов друг друга и без пересекающихся записей.
- **Не применять:** Обе ветки меняют один файл либо вторая использует вывод первой.
- **Устройство:** Разделить предмет работы и свести все части; read-only вариант — независимые проверки. Общая форма — Fan-out / Fan-in.
- **Ограничения:** Неполная часть остаётся видимым пробелом; конкурентность требует поддержки среды.
- **Пример USW:** Отдельно изучить документацию двух модулей, затем собрать общую карту.
- **Проверка пользы:** Сравнить полноту, время и затраты со последовательным исследованием.
- **Происхождение:** [Anthropic](https://www.anthropic.com/engineering/building-effective-agents): Parallelization / Sectioning; рецепт независимых частей — адаптация USW.
