# Последовательный процесс — Pipeline / Sequential workflow

- **Проблема:** Следующая стадия зависит от результата предыдущей.
- **Применять:** Стадии известны заранее и имеют проверяемые входы и выходы.
- **Не применять:** Одного действия достаточно или порядок задач выясняется только в ходе исследования.
- **Устройство:** Передавать результат по цепочке; Prompt chaining — частный случай цепочки модельных вызовов. См. рецепт последовательных стадий в индексе.
- **Ограничения:** Последовательность не требует субагентов, файлов или цикла; ошибка ранней стадии должна остановить зависимые шаги.
- **Пример USW:** Собрать факты, подготовить текст на их основе, проверить текст.
- **Проверка пользы:** Сравнить пропуски требований и стоимость с одним длинным запросом.
- **Происхождение:** [Anthropic](https://www.anthropic.com/engineering/building-effective-agents) описывает Prompt chaining; [ADK](https://adk.dev/workflows/patterns/) — Sequential. Pipeline шире; перенос в Markdown — адаптация USW.
