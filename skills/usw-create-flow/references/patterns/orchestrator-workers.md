# Координатор и исполнители — Orchestrator–workers / Supervisor

- **Проблема:** Состав подзадач неизвестен до изучения входа.
- **Применять:** Координатор может обнаруживать нужные части в согласованном scope и собирать результаты.
- **Не применять:** Известна простая фиксированная цепочка или цена делегирования выше пользы.
- **Устройство:** Координатор выбирает и назначает подзадачи, получает результаты и решает следующий шаг; рецепт — оркестрация с субагентами.
- **Ограничения:** Нужен доступный host вызова агентов, предел работы и единый ответственный за итог; имя паттерна не даёт полномочий.
- **Пример USW:** По найденным импортам определить затронутые модули, назначить исследования и свести выводы.
- **Проверка пользы:** Сравнить покрытие неизвестных заранее частей, время и стоимость с одним исполнителем.
- **Происхождение:** [Anthropic](https://www.anthropic.com/engineering/building-effective-agents): Orchestrator–workers; Supervisor — близкое имя роли, конкретная композиция USW — адаптация.

## Композиция через артефакты

Оркестратор + [Claim Check](claim-check.md) + [изоляция контекста](context-isolation.md) + [Maker–checker](maker-checker.md) — композиция USW из пользовательского исходника, не отдельный отраслевой стандарт. Координатор принимает решения, исполнители создают продукты, проверяющий читает требования и результат. Файлы сокращают повторную передачу текста, но не заменяют проверку.

## Компоненты и автономность

Augmented LLM, retrieval, инструменты и память — базовые компоненты, а не дополнительные формы оркестрации. Agents в статье Anthropic — режим, где модель сама выбирает следующие действия. Для него отдельно согласуют scope, бюджет, остановку и обращение к человеку; выбор паттерна не включает автономность по умолчанию. Markdown USW задаёт инструкции модели, не гарантии runtime.
