# Общее пространство знаний — Blackboard

- **Проблема:** Выбор следующей работы зависит от знаний, накопленных разными участниками.
- **Применять:** Есть общее представление знаний, правила выбора работы, writers и разрешение конфликтов.
- **Не применять:** Есть только папка результатов и координатор, передающий ссылки.
- **Устройство:** Участники обновляют общие знания; управляющий механизм выбирает следующую применимую работу по их состоянию.
- **Ограничения:** Host должен обеспечивать согласованное обновление и обработку конфликтов. USW не создаёт базу или scheduler; без них использовать назначения и Claim Check.
- **Пример USW:** По подтверждённому пробелу в карте требований выбрать следующее исследование, записав факт через согласованного владельца.
- **Проверка пользы:** Проверить полезность выбора задач по знаниям и отсутствие противоречащих обновлений.
- **Происхождение:** [CMU](https://www.cs.cmu.edu/~ModProb/MRsol4.html) объясняет Blackboard. Это условный архитектурный подход, не новое имя обычной папки USW.
