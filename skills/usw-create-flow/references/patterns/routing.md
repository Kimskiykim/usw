# Маршрутизация — Routing / Router / Dispatcher

- **Проблема:** Разным входам нужны разные способы обработки.
- **Применять:** Есть различимые признаки выбора и реально доступные исполнители.
- **Не применять:** Маршрут один либо признаки выбора не позволяют принять решение.
- **Устройство:** Классифицировать вход, выбрать одну ветку, передать ей данные. Координатор, сопровождающий дальнейшую работу, уже может быть Supervisor.
- **Ограничения:** Неясный выбор требует уточнения; название маршрута не создаёт capability.
- **Пример USW:** Запрос о документации направить на чтение документации, о тесте — на проверку теста; неизвестный тип уточнить.
- **Проверка пользы:** Проверить ошибки классификации и стоимость на примерах каждого маршрута.
- **Происхождение:** [Anthropic](https://www.anthropic.com/engineering/building-effective-agents): Routing. Router/Dispatcher — употребляемые названия роли; текстовый рецепт — адаптация USW.
