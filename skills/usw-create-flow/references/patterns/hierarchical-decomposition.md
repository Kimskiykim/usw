# Иерархическое разбиение — Hierarchical decomposition

- **Проблема:** Координатор не справляется с деталями нескольких крупных областей.
- **Применять:** Подобласти достаточно велики, а host поддерживает делегирование следующего уровня.
- **Не применять:** Одного уровня хватает или нельзя ограничить глубину и бюджет.
- **Устройство:** Разбить работу на уровни с возвратом результатов родителю; ограниченная композиция оркестрации.
- **Ограничения:** Задать максимальную глубину и предел ветвей; durable recovery state только у root operation.
- **Пример USW:** Координатор назначает владельцев двух областей; каждый получает право на один дополнительный уровень исследований.
- **Проверка пользы:** Сравнить покрытие и стоимость с плоским распределением, проверить отсутствие потерянных ответов.
- **Происхождение:** [ADK](https://adk.dev/workflows/patterns/): Hierarchical task decomposition. Ограничения глубины и состояния — адаптация USW.
