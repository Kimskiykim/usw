# Общая очередь задач — Shared work queue

- **Проблема:** Независимые работники должны сами брать свободную работу.
- **Применять:** Host предоставляет эксклюзивный захват задания и восстановление после сбоя владельца.
- **Не применять:** Есть лишь Markdown-список или координатор вручную назначает каждую задачу.
- **Устройство:** Работник атомарно захватывает задачу, выполняет и возвращает исход; правила восстановления исключают потерю задания.
- **Ограничения:** Без атомарного захвата нельзя обещать конкурентную очередь. Не имитировать lock-файлы; альтернатива — последовательное назначение координатором.
- **Пример USW:** При доступной очереди свободный исполнитель берёт следующий независимый модуль; при её отсутствии назначения делает координатор.
- **Проверка пользы:** Проверить дубли, потерянные задачи, восстановление и выигрыш относительно назначений.
- **Происхождение:** [Эксперимент Anthropic](https://www.anthropic.com/engineering/building-c-compiler) показывает захват задач. Shared work queue — описательное имя из исходника, не название нового стандарта или реализации USW.
