# Проверка и улучшение — Evaluator–optimizer

- **Проблема:** Первый результат может не удовлетворять проверяемым критериям.
- **Применять:** Обратная связь помогает исправлять результат, а повтор безопасен.
- **Не применять:** Достаточно одной проверки или повтор создаёт необратимый внешний эффект.
- **Устройство:** Сочетать проверку результата и ограниченную доработку; независимый reviewer добавляется по необходимости.
- **Ограничения:** Задать критерии, предел и выход при отсутствии прогресса; одобрение и внешнее действие оставить за циклом.
- **Пример USW:** Проверить черновик по критериям и исправить его не более двух раз; повтор замечания вынести человеку.
- **Проверка пользы:** Сравнить качество до и после, число повторов и стоимость улучшения.
- **Происхождение:** [Anthropic](https://www.anthropic.com/engineering/building-effective-agents): Evaluator–optimizer; композиция рецептов USW адаптирует этот цикл.

Рецепты: [Проверка результата](../recipes/result-check.md), [Ограниченная доработка](../recipes/bounded-refinement.md).
